# AI 润色验收 · 2026-09-16

已完成 AI 提炼模式下“用自己的话解释”的润色功能。

## 产品行为

- 输入回答后，可点击“AI 润色”。建议基于当前知识总结与回答生成，展示涉及的知识点、建议表达、修改说明与知识提醒。
- 生成结果先预览；“采纳建议”仅替换解释正文，“保留原文”关闭建议。采纳后可以撤销，普通保存操作才持久化记录。
- “新的理解”和“有趣的思想点”保持原内容。回答或知识上下文变化时，取消旧请求并丢弃旧建议。
- 无回答、缺少知识总结、离线或正在重新提炼时禁用入口。生成失败保留原文，超出三栏合计长度限制时不能采纳。
- 后端复用登录校验与频率限制，不新增数据库结构；模型密钥仅在服务端使用。应用服务器所需配置已补充至 README。
