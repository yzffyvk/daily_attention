# AI 提炼与知识串联：假数据验收

日期：2026-09-17。使用真实前端组件与浏览器内的预设数据，不调用真实 AI，不修改 Supabase。

## 打开示例

本地服务已启动时，访问：

- [默认验收入口](http://127.0.0.1:4300/)：不需要任何额外参数，默认启用假数据。
- [AI 提炼](http://127.0.0.1:4300/?demo=1&scenario=ai)
- [同主题知识串联](http://127.0.0.1:4300/?demo=1&scenario=map)
- [多主题原文展示](http://127.0.0.1:4300/?demo=1&scenario=mixed)

需要重新启动时，在项目目录运行 `npm run demo`。预览仅监听本机 4300 端口，无需登录或配置 AI 密钥。

## 推荐验收顺序

1. **AI 提炼**：链接已填好，点击「生成知识小结」。约 10 秒内依次显示等待、读取资料、生成和完成。点击「具体经历」等节点查看解释，展开全文和关键辨析；填写三个思考栏目，体验润色建议、采纳/撤销、编辑总结和保存。刷新后可继续查看已保存结果。
2. **同主题串联**：从顶部进入对应场景，点击「串联知识」。可直接打开已保存的「从理解用户，到验证需求」；也可新增串联，选择指南列出的三天，填写探索问题并生成。验收生成动画、概念详情、记录依据/推断/AI 补充、关系说明、讲述提纲、待探索部分和来源快照。
3. **多主题展示**：进入对应场景并新增串联，选择咖啡、宋词、徒步的三个日期。结果完整展示原始记录，不强行构建关系图。列表也预先保存了该示例。
4. **编辑与管理**：知识脉络支持编辑、保存、复制、删除和重新生成；重新生成保留旧版本。更新学习记录后，旧脉络提示来源已变化，并保留生成时快照。
5. **边界状态**：顶部「体验一次生成失败」只影响下一次 AI 提炼或知识串联；失败后再次生成可成功。AI 排队时可取消。切换深浅色和手机宽度检查页面。
6. **重新体验**：顶部「重置示例」恢复预设记录、两条已保存脉络及新的演示用户。主题偏好保留。

## 数据范围

生成内容是固定的虚构学习示例，用于验收界面与交互，不代表真实模型效果。所选日期决定引用范围；混合主题走原始记录展示。预设资料按访问当天生成相对日期，跨月时可翻动日历选择。

演示资料和草稿保存在当前标签页的 sessionStorage 中；刷新和场景切换保留，重置后恢复。浏览器限制存储时回退为内存，此时仅保证当前页面中的切换保留草稿，刷新无法恢复。演示用户采用独立 ID，草稿不与正式账户混用。演示草稿不再等待 IndexedDB，避免内嵌浏览器读取迟迟不返回而持续锁定两种记录方式。4300 预览服务默认启用假数据，只有自动化测试使用 `?fixture=1` 显式关闭；该入口仍使用原有 IndexedDB 草稿逻辑，正式应用不导入演示代码。图片上传和账号服务不在本次演示范围内。
