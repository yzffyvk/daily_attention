# 柔和薄荷视觉更新设计

## 目标

将现有 AI 学习打卡网页调整为低饱和、耐久使用的“柔和薄荷研究手记”风格，并提升“今天你 attention 了吗？”品牌标题的艺术感。此次更新只涉及前端色彩、字体和装饰细节，不修改页面结构、交互流程、后端、数据库或 API。

## 视觉方向

页面继续保持桌面学习工具的克制与清晰，以柔和薄荷色建立主要识别，用深薄荷色保证按钮和文字对比。珊瑚红用于 `attention`、今天和选中状态，旧金色用于标题下划线与少量提示，不让多种强调色平均分布在页面中。

### 色彩令牌

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 页面背景 | `#EDF5F1` | 页面外层背景 |
| 纸张表面 | `#FFFFFF` | 页面容器、输入区域 |
| 柔和表面 | `#F5FAF7` | 次级分区、悬停背景 |
| 主文字 | `#23352F` | 标题和正文 |
| 次级文字 | `#69766F` | 描述、辅助信息 |
| 边框 | `#D7E3DD` | 普通边框和分割线 |
| 强边框 | `#B8CBC2` | 悬停、选中辅助边框 |
| 深薄荷 | `#3D7563` | 主按钮、品牌标识、完成状态 |
| 深薄荷强化 | `#285C4B` | 主按钮悬停和高对比文字 |
| 浅薄荷 | `#D9EEE5` | 完成状态背景和主色淡底 |
| 珊瑚红 | `#BF544B` | `attention`、今天、当前选中 |
| 淡珊瑚 | `#F8E8E4` | 红色状态背景 |
| 旧金 | `#E8D08C` | 标题下划线、小面积提示 |

所有正文与交互文字保持至少 WCAG AA 对比度。浅薄荷和旧金不承载白色正文。

## 字体系统

- 中文品牌标题使用 `ZCOOL XiaoWei`，仅加载常规字重并仅用于品牌标题。
- 英文 `attention` 使用 `Bodoni Moda` 的 600 斜体，作为页面唯一的高表现力字体。
- 正文、表单和数据继续使用现有 Geist 与中文系统无衬线字体，保证密集工具界面的可读性。
- 字体通过 `next/font/google` 加载，并提供宋体、Georgia 等本地回退，避免字体加载失败时出现不可读或布局跳变。

首页和认证页面中的同一品牌标题采用相同字体规则。标题保持单行，不改变现有语义结构；`attention` 下方使用旧金色短划线，装饰不得遮挡字形。

## 状态映射

- 主要操作、已完成打卡：深薄荷和浅薄荷。
- 今天、当前日期、品牌词 `attention`：珊瑚红。
- 提示、庆祝和标题划线：旧金色。
- 键盘焦点：焦点蓝。
- 错误和危险操作继续使用现有错误语义，不以薄荷绿替代。

状态仍通过边框、图标和文字共同表达，不能只依赖颜色。

## 改动范围

1. 在根布局中加载两种品牌展示字体并暴露 CSS 变量。
2. 更新全局色彩变量及少量仍使用硬编码旧配色的前端样式。
3. 更新首页与认证页品牌标题字体、字重和下划线表现。
4. 不调整组件结构、布局尺寸、响应式规则、表单字段和业务行为。

## 验证

- 在首页、登录页、注册页和首次登录设置页检查品牌标题一致性。
- 在 `1440x900` 和当前宽屏预览尺寸检查标题单行、字形不裁切、页面无横向溢出。
- 检查普通、今天、选中、已打卡、禁用和键盘焦点状态。
- 运行相关单元测试、页面结构测试、Lint、类型检查和生产构建。
